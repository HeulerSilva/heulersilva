### 📊 End-to-end Analytics Engineering Pipeline & Data Governance
> Python · DuckDB · dbt · Pandas · Jupyter Notebooks

Built a complete Analytics Engineering pipeline transforming raw, inconsistent data into a governed, decision-ready Gold layer.

**Key engineering decisions:**
- 🔹 Two-layer entity normalization — `LOWER/TRIM` (preventive) + `CASE WHEN` (specific typo resolution)
- 🔹 Deterministic deduplication via `ROW_NUMBER()` Window Function
- 🔹 `GREATEST(..., 0)` numeric guards preventing silent corruption
- 🔹 **38/38 automated dbt tests passing** — uniqueness, not-null & accepted_values enforcement
